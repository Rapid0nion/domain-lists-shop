## 📦 What You Can Find

The project covers multiple types of domain and web research datasets.

### 🌐 Domain Lists

Curated domain collections organized by different characteristics, technologies, TLDs, services, and research criteria.

Examples include:

- Large domain collections
- Top domain lists
- TLD-specific datasets
- Technology-specific domains
- Domain infrastructure datasets
- Domain research collections

### 💳 Payment Systems

Domains associated with websites using various payment platforms and payment technologies.

Examples include:

- PayPal
- Stripe
- Authorize.Net
- Payment-related integrations
- Other payment platforms

### 🛒 CMS & eCommerce

Datasets covering websites using popular content management systems, eCommerce platforms, website builders, and related technologies.

Examples include:

- WordPress
- WooCommerce
- Magento
- PrestaShop
- OpenCart
- Shopify
- Drupal
- Joomla
- TYPO3
- Wix
- Squarespace
- Webflow
- Other CMS and eCommerce platforms

### 📧 Webmail & Email

Datasets related to publicly observable webmail and email technologies.

Examples include:

- Roundcube
- Other webmail platforms
- Email infrastructure research

### 🔐 Security Research

Datasets related to security technologies, vulnerability research, and security-focused web infrastructure.

This may include datasets associated with:

- CVEs
- Security products
- VPN technologies
- Security gateways
- Web security products
- Technology fingerprints

### 📡 Network & Infrastructure

Datasets covering network services, infrastructure technologies, and publicly observable services.

Examples include:

- Web services
- Network infrastructure
- Server technologies
- Hosting technologies
- CDN and proxy technologies

### 🌍 Geo & ASN Data

Datasets related to geographic and network information, including:

- Countries
- Autonomous Systems
- ASN-related research
- IP and network infrastructure
